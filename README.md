# האתר של ד״ר אייל מגורי

אתר סטטי: HTML, CSS ו-JavaScript, בלי שרת ובלי מסד נתונים. אפשר לאחסן אותו בחינם.

## מבנה הקבצים

| קובץ | מה יש בו |
|---|---|
| `data.js` | **כל התוכן**: קורסים, יחידות, שיעורים, נושאים, מחקר ופרויקטים. רוב העדכונים נעשים רק כאן |
| `lab.js` | המעבדה: פרטי המכון, ניסויי SDR, קורס ה-RF ונושאי שיתוף הפעולה |
| `sdr/` | קוד ה-Python לניסויי ה-ADALM-Pluto, והגרפים ב-`sdr/figures/` |
| `app.js` | בניית הדפים: בית, קורסים, נושאים, הכנה למבחנים, מחקר, פרויקטים, אודות וחיפוש |
| `style.css` | עיצוב, כולל מצב כהה והתאמה לטלפון |
| `index.html` | שלד הדף והתפריט |

## עדכונים נפוצים (ב-`data.js`)

- **שיעור חדש:** מוסיפים שורה ב-`lessons` של היחידה המתאימה, עם מזהה הסרטון מ-YouTube, כותרת, אורך ונושאים.
- **פרויקט סטודנטים:** מוסיפים אובייקט ל-`PROJECTS`.
  - הסטטוס הוא אחד מאלה: `open` (פתוח להצטרפות), `active` (בעבודה) או `done` (הושלם).
- **תחום מחקר:** מוסיפים אובייקט ל-`RESEARCH`.
- **נושא חדש:** מוסיפים מפתח ל-`TOPICS`, ואז משתמשים בו ב-`tags` של השיעורים.

הכותרות באתר לא משנות את הכותרות ב-YouTube.

## המעבדה וה-SDR

- **ניסוי חדש:** מוסיפים קובץ `sdr/labNN_*.py` ואובייקט ל-`SDR_LABS` ב-`lab.js`. את הגרף מייצרים עם `python sdr/labNN_*.py --save --no-show`.
- **תוצאות מהחומרה:** אחרי ההרצה על ה-Pluto שומרים את הגרף ב-`sdr/figures/` ומוסיפים אותו לניסוי.
- **לוגו המכון:** שמים את הקובץ ב-`img/` וכותבים את הנתיב ב-`LAB.logo` שב-`lab.js`.

## שתי שפות

- **כתובות:** הגרסה העברית ב-`#/...` והאנגלית ב-`#/en/...`. כפתור השפה עובר לאותו דף בשפה השנייה.
- **אפשר לשלוח קישור ישיר** לגרסה האנגלית, למשל `.../#/en/research` לחברה.
- **תרגום תוכן:** שדות שמסתיימים ב-`_en` (וכותרת שיעור בשדה `en`) הם הגרסה האנגלית. אם חסר תרגום, מוצג הטקסט העברי.
- **טקסטים קבועים** כמו תפריט וכפתורים נמצאים באובייקט `UI` בתחילת `app.js`.

## צפייה מקומית

```bash
python3 -m http.server 8765 --directory website
```

ואז פותחים בדפדפן את http://localhost:8765

## העלאה לאוויר (חינם)

**GitHub Pages:**
1. יוצרים מאגר חדש ב-GitHub.
2. מעלים אליו את תוכן התיקייה הזאת.
3. ב-Settings → Pages בוחרים ענף `main` ותיקיית root.

**Netlify או Cloudflare Pages:** גוררים את התיקייה לממשק שלהם.

**דומיין משלך:** אפשר לחבר דומיין לכל אחד מהשירותים האלה, בעלות של כ-10–15 דולר לשנה.
